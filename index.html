CAMX: one camera-aware layout for every robot dataset.

A cross-embodiment collection converted into a single LeRobot-v3 layout, with per-frame camera poses, intrinsics, end-effector pose and gripper state for every view, so a policy can be trained across handheld, single-arm, bimanual and humanoid data as one corpus.

02 · What's inside

Seventeen embodiments, four morphologies, one schema.

Every source is re-exported to the same LeRobot-v3 layout: meta/, data/ parquet and per-view videos/, with the camera's world pose written for every frame. Hours below are counted from episode lengths at the source frame rate.

Hours by embodiment
Common to every dataset
Camera
Per-frame camera-to-world pose and intrinsics for each view; fisheye views carry a Kannala-Brandt fit.
State
End-effector pose in the same world frame, gripper width, and joint positions where the source recorded them.
Video
480p MP4 per camera view, decoded through the standard LeRobot readers.
Validation
The gripper's URDF is projected through the shipped poses and intrinsics back onto the wrist views. If it sits on the real gripper, the calibration is consistent. See the clips.
Layout
<family>/<project>/<dataset>/ so a download can be scoped to any subtree.

04 · Batch download

One command for the selection.

The datasets you tick in the browser become an hf download call, a Python snippet or a resumable bash loop. Selections persist in this browser and can be exported as JSON to share with collaborators.


        
Downloads are per dataset directory <family>/<project>/<dataset>/ (meta/, data/, videos/). Sizes are estimates from the 480p tree measurement, spread over datasets by frame count.

05 · Validation you can look at

      
The gripper drawn back onto its own cameras.

      
For each dataset family a few episodes are re-rendered with the gripper's URDF (or the recorded camera path and world-up axis where no URDF is released) projected through the dataset's own per-frame poses and intrinsics. Every camera view is stitched side by side.
